# 拟合与曲池算法

本文说明“个人拟合”是如何计算出来的，以及打歌助手里各个曲池的生成条件。

## 1. 输入

参与拟合的数据：

- 非宴谱（`utage` / `utage2p` 不参与）；
- 官方定数、本地定数；
- 成绩、连击状态、游玩次数；
- dxrating.net的曲目标签；
- 水鱼拟合差值；

## 2. 个人拟合

### 2.1 评价定数

先给每张谱一个“评价定数”：

```text
有可靠水鱼差值：
    评价定数 = 官方定数 + 水鱼差值

没有水鱼差值，但有“水/诈称谱”标签：
    评价定数 = 官方定数 + 同档标签先验

其余：
    评价定数 = 官方定数
```

示例：

```text
官方定数 13.6，水鱼差值 +0.12
→ 评价定数 13.72
```

如果 水鱼拟合 比 官方定数 低超过 0.2 ，则会截断，

示例：

```text
官方定数 13.8，水鱼差值 -0.36
→ 评价定数 13.60
```

### 2.2 能力区间

把有成绩的谱按单曲 Rating 从高到低排序，取前 N 张，收集它们的评价定数。

```text
能力下界 = 前 N 张评价定数的 10% 分位
能力上界 = 前 N 张评价定数的 95% 分位
```

再向外放宽 0.3 得到置信区间：

```text
置信下界 = 能力下界 - 0.3
置信上界 = 能力上界 + 0.3
```

示例：

```text
能力下界 13.2，能力上界 14.1
→ 置信区间 [12.9, 14.4]
```

#### N 怎么取

N 不是固定值，按“旧曲 b35 最后一名”的官方定数决定。

- 旧曲不足 35 张时，用最后一张的官方定数；
- 没有旧曲，再看新曲 b15；
- 新曲也不足 15 张，用最后一张；
- 旧曲、新曲都没有，N 取 50。

设这个官方定数为 `x`：

| 官方定数 x | 取的谱数 N |
|---|---|
| x ≤ 12.5 | 50 |
| 12.5 < x < 13.0 | 50 + 72 × (x − 12.5) |
| 13.0 ≤ x < 13.5 | 86 + 84 × (x − 13.0) |
| 13.5 ≤ x < 14.0 | 128 + 144 × (x − 13.5) |
| x ≥ 14.0 | 200 |

结果四舍五入。

示例：

```text
旧曲 b35 最后一名是 13.8
→ N = 128 + 144 × 0.3 = 171.2
→ 取前 171 张
```

如果实际有成绩的谱不足 N 张，就全部取。

### 2.3 标签修正

先算出每个标签的修正量：

```text
正数：这个标签对你更容易
负数：这个标签对你更难
```

单张谱的标签修正：

```text
标签修正 = -(标签均衡系数 × 标签数量系数
           × 这张谱所有相关标签的修正量合计
           × 标签作用范围)
```

绝对值大于 0.3 时会被截断。

标签权重：

```text
评价定数在能力区间内             → ×1.0
能力区间外、但在置信区间内       → ×0.8
置信区间外                       → 不修正
```

示例：

```text
两个弱项标签，修正量合计 -0.15
→ 标签修正约 +0.15（弱项让个人拟合变高，也就是更难）
```

### 2.4 成绩修正

成绩修正只在评价定数落在置信区间内才生效：

```text
成绩修正 = 系数 × 成绩权重

游玩次数 ≥ 10：系数 = 0.2
游玩次数 < 10：系数 = 0.06
```

成绩权重以 100.5% 为基准：低分给正修正，高分给负修正。

示例：

```text
达成率 99.5%，游玩 20 局
→ 成绩修正约 +0.1
```

### 2.5 单谱拟合值

只有评价定数落在置信区间内，才应用成绩修正和标签修正：

```text
个人拟合 = 评价定数 + 成绩修正 + 标签修正
```

单张谱的总修正最多 ±0.3。

示例：

```text
评价定数 13.6
成绩修正 +0.1
标签修正 -0.1
→ 个人拟合 13.6
```

## 3. 曲池条件

### 3.1 公共前提

所有曲池都：

- 排除宴谱；
- 排除当前黑名单谱面；
- 只对常规谱面计算。

旧曲、新曲的 Rating 门槛：

```text
旧曲门槛 = 旧曲 Rating 第 35 名的值
新曲门槛 = 新曲 Rating 第 15 名的值

池子不足 35 / 15 张时，对应门槛按 0 处理
```

单曲 Rating 的推分潜力：

```text
推分潜力 = 按 100.0% 和 100.5% 各算一次 Rating，取较大的那个
```

### 3.2 曲池一览

| 曲池 | 条件 |
|---|---|
| 熟练 `mastered` | 有成绩；达成率 ≥ 100.6%； *能力下界* ≤ 个人拟合 ≤ *能力上界* |
| 推b35 `pushable_b35` | 旧曲；个人拟合 < *置信上界 - 0.15*；达成率 < 100.5%；已在 b35 内，或推分潜力 > b35 门槛 |
| 推b15 `pushable_b15` | 新曲；条件同推b35，但使用新曲门槛 |
| AP推分 `ap` | 达成率 > 100.85%；尚未 AP/AP+；已在 b50 内，或 AP 后 Rating > b35/b15 门槛 |
| 弱点练习 `practice` | 个人拟合在置信区间内；达成率 < 100.6%； *能力区间中点* ≤ 评价定数 ≤ *能力上界*；至少 2 个弱项配置标签，或至少 1 个弱项评价标签 |
| 准度练习 `accuracy` | *能力下界* ≤ 评价定数 ≤ *能力区间中点*；达成率 > 100.7%；尚未 AP/AP+ |
| 有挑战 `challenge` | *能力上界* < 个人拟合 ≤ *置信上界* |
| 待开荒 `unplayed` | 没打过； *能力区间中点* ≤ 评价定数 ≤ *能力上界* |
| 收藏 `favorite` | 谱面已加入收藏 |
| 随机下埋 `underdog` | 自定义卡池；按设置的定数范围、难度、版本、牌子条件等筛选，不使用固定标签 |

### 3.3 条件示例

假设：

```text
本地定数 = 13.8
评价定数 = 13.6
个人拟合 = 13.6
能力区间 = [13.2, 14.1]
置信区间 = [12.9, 14.4]
旧曲门槛 = 13.5
```

则：

```text
达成率 99.8%，个人拟合 13.6，官方定数 13.7
→ 推b35 候选：个人拟合在置信区间内，定数超过旧曲门槛

达成率 100.7%，个人拟合 13.6
→ 熟练：达成率 ≥ 100.6%，且个人拟合在能力区间内

个人拟合 14.2
→ 有挑战：能力上界 14.1 < 14.2 ≤ 置信上界 14.4
```

### 3.4 多标签与优先级

一个谱面可以同时命中多个标签。

打歌助手按卡池取候选：

- `favorite` 只看收藏，不要求分析标签；
- `underdog` 只看自定义筛选，不要求分析标签；
- 其他池要求谱面包含对应标签；
- 黑名单永远排除。
