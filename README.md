# 打歌计划器

- 本地运行的舞萌 DX 数据管理与打歌规划工具。  
- 用于整理游戏数据、管理个人成绩、浏览曲库、点歌、安排推分和打歌计划。

**概括为：**

从本地游戏包生成 **数据库** → 从机台 **抓取成绩** → 分析成绩 **生成用户画像** → 按分析结果和用户设置 **推荐歌曲** → 配合模组实现 **游戏内歌曲自动跳转**

当前版本：`0.2.0`

## 功能

### 数据维护

- 从本地游戏包建立或更新本地数据库
- 联网更新曲库、定数、标签、别名等数据
- 主要数据源：水鱼、落雪、dxrating.net

### 用户与成绩

- 导入 MuNET 存档构建本地成绩库
- 配合 SongRequestLite 模组从机台拉取数据自动构建用户与成绩库
- 新建、删除、切换用户
- 设置头像、修改用户名
- 查看成绩统计、DX Rating
- 支持多个用户分别保存数据

### 歌曲浏览

- 浏览曲库，按曲名、版本、难度、定数、牌子要求等条件筛选
- 查看每首歌、每个难度的详细信息
- 按完成条件、牌子条件统计完成情况
- 查看曲绘、谱面信息和成绩状态
- 可以直接编辑成绩库内的成绩
- 可以将谱面加入收藏或黑名单
- 可以直接向 SongRequestLite 直接发送指令跳转到指定歌曲（点歌）

### 打歌助手

- 分析成绩，给出标签分析雷达图
- 根据用户配置的曲池顺序，生成接下来要打的曲目
- 与 SongRequestLite 模组配合，自动把曲目推送到游戏
- 自动接收结算成绩并更新统计信息

### 卡池预览

- 根据能力画像和分析结果生成推荐曲目
- 按曲池标签查看候选曲目
- 用于在正式打歌前检查各个曲池的候选曲目

## 运行环境

- Windows 10 / 11
- Python 3.10 或更高版本
- UnityPy
- Pillow
- SongRequestLite 模组（可选，仅跳歌推送和机台抓取存档需要）

> 只浏览曲库、统计成绩或做拟合不需要安装模组。

首次使用前运行：

```text
check_env.bat
```

检查通过后启动：

```text
python start.py
```

浏览器会自动打开本机页面。

也可以手动指定：

```text
python start.py --port 20005
python start.py --no-browser
python start.py --host 0.0.0.0
```

## 数据说明
 
首次使用时需要在网页里选择自己的游戏包目录，构建本地数据库 `data/`。

`dataUI_VG/` 保存 `tools/ui_flat` 生成的 UI 素材。

首次启动或素材缺失时，会自动生成 `dataUI_VG/`。

`dataUser/` 保存个人成绩、头像和用户配置。

默认使用代码生成的 UI 素材，字体使用微软雅黑；该模式为 0.2.0 新增。

另外支持图片 UI 素材，路径如下：

`dataUI/` 保存 UI 贴图。

`dataUI/Fonts/` 保存两个 UI 界面用到的字体。

由于包含游戏素材，个人使用的 `dataUI/` 不随本项目分发。
